# Daniel Nadal — Quiet Systems

## Website introduction

**Quiet Systems** is Daniel Nadal's personal portfolio website. It presents a
calm, accessible record of his education, technical skills, projects,
professional experience, certifications, leadership, and contact details.

The portfolio is built around a simple idea: technology should reduce friction,
not relocate it. Its visual language uses warm colour, editorial typography,
soft motion, and clear content structure to make technical work easier to
understand.

The site is a lightweight static website with no framework, build process, or
external dependencies. It works as a direct file open or through a small local
web server.

## Run locally

No package installation or build step is required.

Open [`index.html`](index.html) directly, or serve the folder with Python:

```bash
python -m http.server 8000
```

Then visit <http://localhost:8000>.

Using a local server is recommended when opening certificate PDFs and testing
the site in a browser. The page is designed for current Chrome, Edge, Safari,
and Firefox.

## Customisation

- Update personal copy, experience, projects, or credentials in
  [`index.html`](index.html).
- Update layout, colours, typography, and responsive behaviour in
  [`styles.css`](styles.css).
- Update theme and menu behaviour in [`script.js`](script.js).
- Replace the portrait at `assets/portrait-hero.jpg`.
- Replace the résumé at `assets/Daniel-Nadal-Resume.pdf`.
- Add certificate PDFs to `assets/certs/` and link them from the credentials
  section.
- Bump the `styles.css?v=` or `script.js?v=` query value in `index.html` after
  changing either file if browser cache needs to be refreshed.
